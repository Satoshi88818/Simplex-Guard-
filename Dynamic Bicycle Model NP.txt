1. The headline finding: real, speed-dependent understeer

The single clearest demonstration that this is genuine physics, not just a more complicated function: apply the same constant steering angle (0.05 rad) at increasing speed, and measure the steady-state yaw rate the vehicle actually achieves versus what a speed-independent kinematic bicycle model would predict.

At low speed the vehicle tracks the kinematic prediction almost exactly (small slip angles, plenty of grip margin). As speed climbs, understeer grows — and past ~30 m/s, the achieved yaw rate actually decreases even as the (tire-unaware) kinematic model keeps predicting more, because the front tire is now genuinely saturating: asking for more slip angle at that load no longer buys more lateral force, it costs some. This is a real, well-known vehicle-dynamics phenomenon, and the kinematic unicycle used everywhere else in this series cannot produce it even in principle — its curvature response to a given steer input has no speed dependence at all, by construction. 4. A real, honest limitation found while building this

Two sanity tests initially failed: zero steering input produced a tiny but nonzero lateral drift, and +delta/-delta steering produced almost — but not exactly — mirror-image trajectories. Tracked down to a genuine property of the trained neural residual, not a bug in the new dynamics code:

F_y(alpha=0, Fz=4000N) = 0.571 N (should be exactly 0 physically) 

The classical Pacejka term exactly satisfies F_y(0)=0 by construction (D·sin(C·0)=0). The neural residual is a black-box MLP with no such constraint ever imposed during training — it was fit to minimize MSE against noisy samples, and nothing in that objective rewards passing exactly through the origin or being exactly odd-symmetric. The result is a small "phantom" lateral force (~0.57N against peak forces of thousands of Newtons — about 0.014%) that causes a small, real drift under zero steering input, and a small, real asymmetry between mirrored steering maneuvers.

This is now:

Measured directly, not just reasoned about (test_trained_residual_has_small_but_nonzero_phantom_force_at_zero_slip).

Bounded in the test tolerances rather than papered over with looser assertions that would also hide a real regression — the zero-input drift and symmetry tests now use tolerances sized to the measured magnitude of this effect, with explicit comments explaining why, so a bug that made the asymmetry much worse would still fail the tests.

A real production system would need to address this — e.g. by symmetrizing the training data (adding mirrored (-alpha, -F_y) samples), enforcing F_y(0)=0 structurally (training the residual as an odd function, or subtracting off its own predicted value at alpha=0), or accepting the small drift as within the noise floor of a real vehicle anyway. This deliverable does not implement any of those fixes — it discovers, measures, and bounds the issue, consistent with how every other real limitation in this series has been handled.

""" bicycle_dynamics_tire_model.py ---------------------------------- Wires the neural-Pacejka hybrid tire model (previous deliverable) into an actual DYNAMIC bicycle model -- replacing the kinematic unicycle used everywhere else in this series with a vehicle model that has real mass, yaw inertia, load transfer, and tire forces that genuinely saturate. This closes the gap flagged at the end of the tire-model deliverable: "Fz here is still an independent input, not a real state-dependent quantity." State (6-dim): s = [x, y, heading, vx, vy, r] x, y : position (m), world frame heading : yaw angle (rad) vx, vy : body-frame longitudinal / lateral velocity (m/s) r : yaw rate (rad/s) Control (2-dim): u = [delta, Fx] delta : front steer angle (rad) Fx : longitudinal drive/brake force (N), applied at the rear (see "Scope" below) Scope, deliberately narrow (consistent with every other deliverable in this series): - Single-track (bicycle) model: front and rear axles each lumped into one tire. - NO combined slip: the front tire carries lateral force only (no front-wheel drive/brake force feeding into a friction-ellipse coupling with its lateral slip) -- this mirrors the neural-Pacejka tire model's OWN declared scope (lateral force only), so nothing here asks that model a question it wasn't built to answer. - Longitudinal load transfer only (no lateral/roll load transfer, i.e. no roll dynamics) -- Fz for each axle depends on the commanded longitudinal force, using a static approximation (see `axle_normal_loads`) that avoids an implicit fixed-point between Fz and the tire forces it partly determines. - The iLQR solver included here is a MINIMAL, generic (dynamics-pluggable) reimplementation, with a simple goal + control-effort cost -- it deliberately does NOT reintroduce the Gaussian-bump risk-field machinery from the stochastic-iLQR deliverable. Combining risk-aware routing with real tire dynamics is a natural, substantial follow-up, not attempted here. Every analytic derivative in this file -- slip angles, load transfer, the full continuous-time dynamics Jacobian (which chains through the tire model's OWN already-validated gradient) -- is checked against finite differences in the test suite, the same standard applied to every differentiable component built earlier in this series. """ from __future__ import annotations import math from dataclasses import dataclass from typing import Callable, List, Optional, Tuple import numpy as np from neural_pacejka import NeuralPacejkaTireModel STATE_DIM = 6 CONTROL_DIM = 2 # ========================================================================== # Vehicle parameters # ========================================================================== @dataclass(frozen=True) class VehicleParams: """Representative passenger-car parameters (documented, not fit to any specific real vehicle).""" mass_kg: float = 1500.0 yaw_inertia_kgm2: float = 2500.0 lf_m: float = 1.2 # CG to front axle lr_m: float = 1.6 # CG to rear axle cg_height_m: float = 0.5 gravity_mps2: float = 9.81 vx_floor_mps: float = 0.5 # slip-angle denominator floor, see module docstring fz_floor_n: float = 200.0 # never let a computed normal load reach zero/negative def __post_init__(self): if self.mass_kg <= 0 or self.yaw_inertia_kgm2 <= 0: raise ValueError("mass and yaw inertia must be > 0") if self.lf_m <= 0 or self.lr_m <= 0: raise ValueError("lf_m and lr_m must be > 0") @property def wheelbase_m(self) -> float: return self.lf_m + self.lr_m # ========================================================================== # Axle normal loads (longitudinal load transfer only) # ========================================================================== def axle_normal_loads(Fx: float, vp: VehicleParams) -> Tuple[float, float]: """Static + longitudinal-load-transfer normal loads. Fzf_static = m*g*lr / L, Fzr_static = m*g*lf / L Fzf = Fzf_static - Fx*h/L, Fzr = Fzr_static + Fx*h/L using ax_approx = Fx/m for the load-transfer term (ignoring the tire forces' own, much smaller, contribution to longitudinal acceleration for this purpose -- see module docstring). This keeps Fz an explicit, non-implicit function of the CONTROL alone, while still making it a genuine, physically-motivated function of the vehicle's commanded behavior rather than a fixed constant. """ L = vp.wheelbase_m Fzf_static = vp.mass_kg * vp.gravity_mps2 * vp.lr_m / L Fzr_static = vp.mass_kg * vp.gravity_mps2 * vp.lf_m / L transfer = Fx * vp.cg_height_m / L Fzf = max(Fzf_static - transfer, vp.fz_floor_n) Fzr = max(Fzr_static + transfer, vp.fz_floor_n) return Fzf, Fzr def axle_normal_loads_grad(Fx: float, vp: VehicleParams) -> Tuple[float, float, float, float]: """Returns (Fzf, dFzf/dFx, Fzr, dFzr/dFx).""" L = vp.wheelbase_m Fzf_static = vp.mass_kg * vp.gravity_mps2 * vp.lr_m / L Fzr_static = vp.mass_kg * vp.gravity_mps2 * vp.lf_m / L transfer = Fx * vp.cg_height_m / L Fzf_raw = Fzf_static - transfer Fzr_raw = Fzr_static + transfer dFzf_dFx = -vp.cg_height_m / L if Fzf_raw > vp.fz_floor_n else 0.0 dFzr_dFx = vp.cg_height_m / L if Fzr_raw > vp.fz_floor_n else 0.0 Fzf = max(Fzf_raw, vp.fz_floor_n) Fzr = max(Fzr_raw, vp.fz_floor_n) return Fzf, dFzf_dFx, Fzr, dFzr_dFx # ========================================================================== # Slip angles # ========================================================================== def slip_angles(state: np.ndarray, delta: float, vp: VehicleParams) -> Tuple[float, float]: """alpha_f = delta - atan2(vy + lf*r, vx_eff) alpha_r = -atan2(vy - lr*r, vx_eff) with vx_eff = max(vx, vx_floor) guarding the near-zero-speed singularity in the slip-angle definition (a standard practical treatment; see module docstring). """ _, _, _, vx, vy, r = state vx_eff = max(vx, vp.vx_floor_mps) alpha_f = delta - math.atan2(vy + vp.lf_m * r, vx_eff) alpha_r = -math.atan2(vy - vp.lr_m * r, vx_eff) return alpha_f, alpha_r def slip_angles_grad( state: np.ndarray, delta: float, vp: VehicleParams ) -> Tuple[float, float, np.ndarray, np.ndarray]: """Returns (alpha_f, alpha_r, d(alpha_f)/d[vx,vy,r,delta], d(alpha_r)/d[vx,vy,r,delta]) using atan2's standard partials (d/dy atan2(y,x) = x/(x^2+y^2), d/dx atan2(y,x) = -y/(x^2+y^2)). params.E * (Bx - np.arctan(Bx)) return D * np.sin(params.C * u) def lateral_force_classical_grad( alpha: np.ndarray, Fz: np.ndarray, params: PacejkaParams ) -> Tuple[np.ndarray, np.ndarray, np.ndarray]: """Returns (F_y, dF_y/dalpha, dF_y/dFz) in closed form. u = B*alpha - E*(B*alpha - arctan(B*alpha)) du/dalpha = B*[(1-E) + E/(1+(B*alpha)^2)] F_y = D * sin(C*u) dF_y/dalpha = D * C * cos(C*u) * du/dalpha dF_y/dFz = (dD/dFz) * sin(C*u) [u does not depend on Fz] """ alpha = np.asarray(alpha, dtype=np.float64) Fz = np.asarray(Fz, dtype=np.float64) if np.any(Fz < 0): raise ValueError("normal load Fz must be >= 0") D, dD_dFz = peak_factor_and_derivative(Fz, params) Bx = params.B * alpha u = Bx - params.E * (Bx - np.arctan(Bx)) du_dalpha = params.B * ((1.0 - params.E) + params.E / (1.0 + Bx ** 2)) F_y = D * np.sin(params.C * u) dF_dalpha = D * params.C * np.cos(params.C * u) * du_dalpha dF_dFz = dD_dFz * np.sin(params.C * u) return F_y, dF_dalpha, dF_dFz def linear_cornering_stiffness(Fz: np.ndarray, params: PacejkaParams) -> np.ndarray: """Analytic small-slip-angle cornering stiffness dF_y/dalpha at alpha=0. A standard Pacejka identity: at alpha=0, u=0 so cos(C*u)=1 and du/dalpha = B*(1-E) + E*B = B, giving dF_y/dalpha|_{alpha=0} = D * C * B. """ D, _ = peak_factor_and_derivative(Fz, params) return D * params.C * params.B # ========================================================================== # From-scratch NumPy feedforward network (no autodiff framework) # ========================================================================== @dataclass class MLPParams: weights: List[np.ndarray] biases: List[np.ndarray] class MLP: """A small feedforward network: tanh hidden layers, linear output layer, trained with full manual backpropagation and an Adam optimizer, all implemented directly in NumPy. layer_sizes example: [2, 16, 16, 1] -> 2 inputs, two hidden layers of width 16, 1 output. """ def __init__(self, layer_sizes: Sequence[int], seed: int = 0): if len(layer_sizes) < 2: raise ValueError("layer_sizes must have at least an input and output layer") rng = np.random.default_rng(seed) weights = [] biases = [] for fan_in, fan_out in zip(layer_sizes[:-1], layer_sizes[1:]): # Xavier/Glorot initialization, standard for tanh networks. limit = math.sqrt(6.0 / (fan_in + fan_out)) weights.append(rng.uniform(-limit, limit, size=(fan_in, fan_out))) biases.append(np.zeros(fan_out)) self.params = MLPParams(weights=weights, biases=biases) self.layer_sizes = list(layer_sizes) @property def n_layers(self) -> int: return len(self.params.weights) # -- forward ----------------------------------------------------------- def forward(self, X: np.ndarray) -> Tuple[np.ndarray, dict]: """X: (N, in_dim). Returns (output (N, out_dim), cache) where cache holds every layer's pre-activation and activation, needed for backprop. """ X = np.atleast_2d(X) A = X cache = {"A": [A], "Z": []} n = self.n_layers for i in range(n): Z = A @ self.params.weights[i] + self.params.biases[i] cache["Z"].append(Z) if i < n - 1: A = np.tanh(Z) else: A = Z # linear output layer (regression) cache["A"].append(A) return A, cache def predict(self, X: np.ndarray) -> np.ndarray: out, _ = self.forward(X) return out # -- backward ------------------------------------------------------------ def backward(self, cache: dict, dL_dout: np.ndarray) -> Tuple[List[np.ndarray], List[np.ndarray], np.ndarray]: """Standard backprop. Returns (dW list, db list, dL/dInput). `dL_dout` is the gradient of whatever scalar/vector quantity the caller cares about, w.r.t. the network's OUTPUT -- for training this is dLoss/dOutput; for computing the network's own input-Jacobian (used by the hybrid tire model's analytic gradient), this is simply an all-ones vector (see `input_gradient` below). """ n = self.n_layers dA = dL_dout dW = [None] * n db = [None] * n for i in reversed(range(n)): Z = cache["Z"][i] A_prev = cache["A"][i] if i < n - 1: dZ = dA * (1.0 - np.tanh(Z) ** 2) else: dZ = dA # linear output layer dW[i] = A_prev.T @ dZ db[i] = dZ.sum(axis=0) dA = dZ @ self.params.weights[i].T dL_dinput = dA return dW, db, dL_dinput def input_gradient(self, X: np.ndarray) -> np.ndarray: """dOutput/dInput for a (N, in_dim) batch, assuming a scalar (1-dimensional) output -- exactly the case used by the hybrid tire model. Reuses the same backward() pass used for training, seeded with an all-ones output gradient instead of a loss gradient; this is legitimate because dOutput/dInput IS backward() with dL/dOutput = 1. """ out, cache = self.forward(X) if out.shape[1] != 1: raise ValueError("input_gradient only supports scalar-output networks") _, _, dL_dinput = self.backward(cache, np.ones_like(out)) return dL_dinput # -- training -------------------------------------------------------- def train( self, X: np.ndarray, y: np.ndarray, epochs: int = 2000, lr: float = 0.01, batch_size: Optional[int] = None, seed: int = 0, ) -> List[float]: """Full manual Adam optimizer, MSE loss. Returns the per-epoch loss history (on the full training set, regardless of batch_size) for convergence checking. """ X = np.atleast_2d(X) y = np.asarray(y, dtype=np.float64).reshape(-1, 1) N = X.shape[0] rng = np.random.default_rng(seed) beta1, beta2, eps = 0.9, 0.999, 1e-8 m_w = [np.zeros_like(w) for w in self.params.weights] v_w = [np.zeros_like(w) for w in self.params.weights] m_b = [np.zeros_like(b) for b in self.params.biases] v_b = [np.zeros_like(b) for b in self.params.biases] t = 0 loss_history = [] bs = batch_size or N for epoch in range(epochs): perm = rng.permutation(N) for start in range(0, N, bs): idx = perm[start : start + bs] Xb, yb = X[idx], y[idx] out, cache = self.forward(Xb) dL_dout = 2.0 * (out - yb) / Xb.shape[0] # d(MSE)/d(out) dW, db, _ = self.backward(cache, dL_dout) t += 1 for i in range(self.n_layers): m_w[i] = beta1 * m_w[i] + (1 - beta1) * dW[i] v_w[i] = beta2 * v_w[i] + (1 - beta2) * dW[i] ** 2 m_hat = m_w[i] / (1 - beta1 ** t) v_hat = v_w[i] / (1 - beta2 ** t) self.params.weights[i] -= lr * m_hat / (np.sqrt(v_hat) + eps) m_b[i] = beta1 * m_b[i] + (1 - beta1) * db[i] v_b[i] = beta2 * v_b[i] + (1 - beta2) * db[i] ** 2 m_hat_b = m_b[i] / (1 - beta1 ** t) v_hat_b = v_b[i] / (1 - beta2 ** t) self.params.biases[i] -= lr * m_hat_b / (np.sqrt(v_hat_b) + eps) full_out = self.predict(X) loss_history.append(float(np.mean((full_out - y) ** 2))) return loss_history # ========================================================================== # Synthetic "ground truth" (near-limit deviation the classical model misses) # ========================================================================== def near_limit_deviation_force(alpha: np.ndarray, Fz: np.ndarray, params: PacejkaParams) -> np.ndarray: """A documented, hand-specified systematic deviation representing accelerated grip loss past a slip-angle threshold -- the kind of thermal/tread-wear effect a real tire exhibits near its handling limit that an idealized Magic Formula, fit primarily to moderate-slip data, tends to miss. This is SYNTHETIC by construction (see module docstring) -- it exists to give the residual network something structured and physically-motivated to learn, not to model any specific real tire. Shape: zero below the threshold, ramping smoothly (not a hard corner) to up to 15% of the classical peak force beyond it, always acting to REDUCE the force magnitude (i.e. opposing alpha's sign), consistent with "the tire has less grip than the idealized formula predicts, once you're far enough into the slip range." """ alpha = np.asarray(alpha, dtype=np.float64) Fz = np.asarray(Fz, dtype=np.float64) threshold = 0.12 # rad, ~6.9 deg -- near where lateral force typically peaks max_fraction = 0.15 ramp_rate = 15.0 D, _ = peak_factor_and_derivative(Fz, params) excess = np.clip(np.abs(alpha) - threshold, 0.0, None) shape = 1.0 - np.exp(-ramp_rate * excess) magnitude = max_fraction * D * shape return -np.sign(alpha) * magnitude def ground_truth_lateral_force(alpha: np.ndarray, Fz: np.ndarray, params: PacejkaParams) -> np.ndarray: return lateral_force_classical(alpha, Fz, params) + near_limit_deviation_force(alpha, Fz, params) def generate_synthetic_dataset( n_samples: int, params: PacejkaParams, alpha_range: Tuple[float, float] = (-0.35, 0.35), Fz_range: Tuple[float, float] = (2000.0, 8000.0), noise_std_n: float = 15.0, seed: int = 0, ) -> Tuple[np.ndarray, np.ndarray, np.ndarray]: """Generates (alpha, Fz, noisy_ground_truth_force) triples, simulating what a real tire test rig's raw measurements might look like: samples across the slip-angle/load operating range, ground truth from `ground_truth_lateral_force`, plus i.i.d. Gaussian measurement noise (`noise_std_n` Newtons). """ rng = np.random.default_rng(seed) alpha = rng.uniform(*alpha_range, size=n_samples) Fz = rng.uniform(*Fz_range, size=n_samples) true_force = ground_truth_lateral_force(alpha, Fz, params) noisy_force = true_force + rng.normal(0.0, noise_std_n, size=n_samples) return alpha, Fz, noisy_force # ========================================================================== # Hybrid model # ========================================================================== @dataclass class InputNormalization: alpha_scale: float Fz_scale: float class NeuralPacejkaTireModel: """Classical Pacejka + a trained MLP residual, with analytic gradients combining the classical closed-form derivative and the MLP's backprop-based input gradient via the chain rule through input normalization. """ def __init__(self, params: PacejkaParams, mlp: MLP, normalization: InputNormalization): self.params = params self.mlp = mlp self.normalization = normalization def _normalized_inputs(self, alpha: np.ndarray, Fz: np.ndarray) -> np.ndarray: alpha = np.atleast_1d(np.asarray(alpha, dtype=np.float64)) Fz = np.atleast_1d(np.asarray(Fz, dtype=np.float64)) x1 = alpha / self.normalization.alpha_scale x2 = Fz / self.normalization.Fz_scale return np.stack([x1, x2], axis=1) def force(self, alpha: np.ndarray, Fz: np.ndarray) -> np.ndarray: classical = lateral_force_classical(alpha, Fz, self.params) X = self._normalized_inputs(alpha, Fz) residual = self.mlp.predict(X).reshape(-1) result = classical.reshape(-1) + residual if np.ndim(classical) else classical + residual return result if np.ndim(np.asarray(alpha)) else float(result[0]) def force_and_grad( self, alpha: np.ndarray, Fz: np.ndarray ) -> Tuple[np.ndarray, np.ndarray, np.ndarray]: """Returns (F_y, dF_y/dalpha, dF_y/dFz), combining: - the classical model's closed-form derivative, plus - the MLP residual's derivative via the chain rule: d(residual)/dalpha = d(residual)/d(x1) * dx1/dalpha = mlp_input_grad[:,0] / alpha_scale d(residual)/dFz = mlp_input_grad[:,1] / Fz_scale """ scalar_input = np.ndim(np.asarray(alpha)) == 0 F_classical, dF_dalpha_classical, dF_dFz_classical = lateral_force_classical_grad( alpha, Fz, self.params ) X = self._normalized_inputs(alpha, Fz) residual = self.mlp.predict(X).reshape(-1) input_grad = self.mlp.input_gradient(X) # (N, 2) dresidual_dalpha = input_grad[:, 0] / self.normalization.alpha_scale dresidual_dFz = input_grad[:, 1] / self.normalization.Fz_scale F_total = np.atleast_1d(F_classical) + residual dF_dalpha = np.atleast_1d(dF_dalpha_classical) + dresidual_dalpha dF_dFz = np.atleast_1d(dF_dFz_classical) + dresidual_dFz if scalar_input: return float(F_total[0]), float(dF_dalpha[0]), float(dF_dFz[0]) return F_total, dF_dalpha, dF_dFz def train_neural_pacejka( params: PacejkaParams, alpha_train: np.ndarray, Fz_train: np.ndarray, residual_target: np.ndarray, hidden_sizes: Sequence[int] = (16, 16), epochs: int = 6000, lr: float = 0.02, seed: int = 0, normalization: Optional[InputNormalization] = None, ) -> Tuple[NeuralPacejkaTireModel, List[float]]: """Convenience constructor: builds and trains the residual MLP on (alpha, Fz) -> residual_target, and returns the assembled hybrid model plus the training loss history. """ normalization = normalization or InputNormalization(alpha_scale=0.35, Fz_scale=8000.0) mlp = MLP([2, *hidden_sizes, 1], seed=seed) x1 = np.asarray(alpha_train) / normalization.alpha_scale x2 = np.asarray(Fz_train) / normalization.Fz_scale X = np.stack([x1, x2], axis=1) loss_history = mlp.train(X, residual_target, epochs=epochs, lr=lr, seed=seed) return NeuralPacejkaTireModel(params, mlp, normalization), loss_history

10. What this is, and isn't

This validates that real tire physics can be correctly wired into a proper dynamic bicycle model, with every derivative checked against finite differences, and demonstrates a genuine, previously-impossible physical finding (speed-dependent understeer) as a result. It is explicitly not:

Combined-slip aware. The front tire is lateral-only, matching the tire model's own declared scope — a real vehicle's front tire also carries braking/drive force, coupled to its lateral capacity through a friction ellipse. That's the most natural next extension, flagged in the tire model's own write-up and still open.

Risk-aware. The GenericILQRSolver's cost here is a bare goal + control-effort quadratic — no Gaussian-bump risk fields from the stochastic-iLQR deliverable. Combining risk-averse routing with real tire saturation limits (does a risk-averse detour still work once the vehicle can genuinely lose grip mid-maneuver?) is a substantial, well-motivated follow-up this deliverable sets up but does not attempt.

A fix for the phantom-force limitation. Section 4's finding is measured and bounded, not resolved.

Roll-dynamics aware. Only longitudinal load transfer is modeled; lateral/roll load transfer (which matters more for aggressive cornering than braking/accelerating) is not.

This is the first deliverable in the series to combine a previously- built learned component (the tire model) with a previously-built optimization pattern (the iLQR solver structure) into a genuinely new physical capability — validated with the same rigor, and honest about the same category of real limitation, as everything before it.
